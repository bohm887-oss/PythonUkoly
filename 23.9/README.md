# Osobní vizitka

[![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat&logo=html5&logoColor=white)](https://developer.mozilla.org/en-US/docs/Web/HTML)
[![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat&logo=css3&logoColor=white)](https://developer.mozilla.org/en-US/docs/Web/CSS)

Moderní, responzivní webová vizitka navržená pro přehlednou prezentaci kontaktních údajů, dovedností a odkazů na sociální sítě. Projekt klade důraz na čistý design, rychlé načítání a přístupnost na všech typech zařízení.

---

## Hlavní Funkce

* **Předváděcí rozhraní (Hero Section):** Krátké představení s profi fotografií / logem a nadpisem.
* **Responzivní Design:** Plně přizpůsobeno pro mobilní zařízení, tablety i desktopy (Mobile-First přístup).
* **Kontaktní Sekce:** Rychlé odkazy na e-mail, telefon a sociální sítě (LinkedIn, GitHub atd.).
* **Vysoký Výkon:** Čistý kód bez zbytečných závislostí zajišťující okamžité načtení stránky.

---

## Použité Technologie

* **HTML5** – Sémantická struktura webu
* **CSS3** – Stylování (Flexbox / CSS Grid, CSS proměnné pro snadnou úpravu témat)
